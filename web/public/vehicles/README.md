# Prototype vehicle imagery

The two vehicle images in this directory are official Mazda USA 2026 CX-5
Premium Plus product renders downloaded from the Mazda vehicle visualizer on
July 31, 2026:

- `2026-cx5-premium-plus-machine-gray.png` — Machine Gray Metallic (46G)
- `2026-cx5-premium-plus-soul-red.png` — Soul Red Crystal Metallic (46V)
- `2026-cx5-select-polymetal-gray.jpg` — 2.5 S Select in Polymetal Gray
  Metallic (47C), Mazda visualizer exterior frame 001 downloaded August 1, 2026
- `2026-cx5-select-polymetal-gray-cutout.png` — transparent-background
  prototype cutout derived from that same official visualizer frame

Source: <https://www.mazdausa.com/vehicles/cx-5>

These files are retained for private prototype evaluation. Mazda owns the
underlying imagery and marks its site content as all rights reserved. Replace
these assets with owner-supplied photography or separately licensed imagery
before public or commercial distribution.

The Polymetal Gray cutout removes the visualizer's studio background while
preserving the vehicle, its glass, and the original product-render angle. It is
used only for consistent presentation beside the other local vehicle cards.

`2024-cx5-platinum-quartz-select-render.png` is an AI-assisted isolated product
render derived from Mazda USA's official 2025 CX-5 2.5 S Select visualizer
frame in Platinum Quartz Metallic (47S). The 2025 visualizer uses the same
CX-5 generation and references MY24 Select-package assets. It is used as a
matching trim and color representative until an owner-supplied photo is
available; it is not presented as Elie's exact vehicle.
